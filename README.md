Overwatch: Fleet Control (Agentic AI Task Executioner)
Overwatch: Fleet Control is an advanced orchestration system designed to move industrial automation from rigid, scripted processes to intelligent, autonomous agentic workflows. By integrating a "Strategist Node" powered by Gemini 2.0 Flash, the system allows for dynamic task assignment, real-time emergency response, and proactive maintenance.

💡 The Problem
Traditional industrial automation relies on rigid, pre-programmed scripts. This leads to several critical issues:
Logic Failure: Small environmental changes cause system-wide stalls.
The Reaction Gap: Human intervention is too slow during emergencies (e.g., hazardous leaks).
Operational Blindness: Robots function as isolated tools, failing to share data regarding battery health or mission status, resulting in inefficient resource management.

🚀 The Solution
Overwatch implements an Agentic AI Fleet Orchestration layer to handle complexity and chaos:
Strategist Node: Interprets natural language commands to generate logical mission plans.
Reasoning-Based Execution: Dynamically evaluates fleet status (proximity, battery levels, tool capability) before assigning tasks.
Self-Healing Loop: Autonomous power management ensures units relocate to charging bays when necessary, maintaining 24/7 operational readiness.
Chaos Resilience: A priority-based override system that halts routine work to address immediate hazards.

🛠 Tech Stack
AI Core: Gemini 2.0 Flash (Strategist Node)
Logic & State Management: Python & LangGraph
Communication: JSON Telemetry (for real-time unit vitals)
Interface: Streamlit (Custom Terminal HUD)

📊 Key Features
Autonomous Dispatch: Command a fleet with simple natural language (e.g., "Secure the factory").
Real-time HUD: Monitor unit vitals, location maps, and mission progress.
Mission Logging: Records every action for predictive maintenance and performance analysis.
Safety Authorization: Requests human intervention for high-risk operations.

🏢 Real-World Use Cases
Smart Warehousing: Optimizing AMR paths and battery cycles in fulfillment centers.
Hazardous Refineries: Managing specialized units for leak/fire response without endangering personnel.
Automated Manufacturing: Facilitating "Lights-Out" factories with minimal human oversight.
Search & Rescue: Coordinating drone/ground vehicle swarms in disaster zones.
